# homeassistant-4heat

Home Assistant Component for 4heat stove devices

### Installation

Copy this folder to `<config_dir>/custom_components/4heat/`.

### HACS
Search for 4Heat

### Configuration

Configure the integration in the Home Assistant UI. For the supported stove
readings and optional boiler slider and power selector, see the [README](README.md).
